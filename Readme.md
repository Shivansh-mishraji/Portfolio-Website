## 🚀 Interactive UI & Performance Engine

This portfolio isn't just a static page; it's an optimized web experience.

- **Interactive 3D Dynamics**: Features a dynamic HTML5 particle background with physics tracking, glassmorphism UI components, and integrated 3D react-fiber cinematic headers.
- **Extreme Mobile Smoothness**: 
  - ⚡ **GPU Throttling**: Particle algorithms intelligently deactivate on screens `< 768px` to guarantee 60FPS scrolling.
  - 🌀 **Scroll Debouncing**: Custom listeners use `requestAnimationFrame` with passive event binding.
  - 📱 **Touch Optmized**: UI strictly enforces `(hover: hover)` media queries to eliminate sticky-hover glitches on phones.

## 🛡️ Enterprise Security

- **Zero Tabnabbing**: All external portfolio links and GitHub redirects are safely sandboxed with `rel="noopener noreferrer"`.
- **Spam Mitigation**: Contact forms are secured against bots via invisible honeypot architectures (`_honey` attributes), dropping payloads silently without annoying users with CAPTCHAs.
- **Strict Scoping**: Custom JavaScript is encapsulated securely inside ES6 Modules to prevent namespace collisions.

## 💻 Running Locally

To run this project locally, clone the repository and run the Vite development server:

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

To build for production:

```bash
npm run build
```
