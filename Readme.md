# Shivansh Mishra — Portfolio Website

A highly optimized, fully responsive, and interactive personal portfolio showcasing projects in Machine Learning, Data Science, and Full-Stack AI Product Development.

## 🚀 Features

- **Interactive UI/UX**: Dynamic HTML5 particle background with $O(N^2)$ physics tracking, glassmorphism UI components, and integrated 3D react-fiber cinematic headers.
- **Extreme Mobile Smoothness**: 
  - Dynamic GPU throttling: Particle connection algorithms intelligently deactivate on screens `< 768px` to guarantee 60FPS scrolling and save battery.
  - Custom scroll listeners use `requestAnimationFrame` with passive event binding.
  - UI strictly enforces `(hover: hover) and (pointer: fine)` media queries to eliminate mobile sticky-hover glitches.
- **Enterprise Security**:
  - **Zero Tabnabbing**: All external portfolio links and GitHub redirects are safely sandboxed with `rel="noopener noreferrer"`.
  - **Spam Mitigation**: Contact forms are secured against automated bots via hidden honeypot architectures (`_honey` attributes), dropping payloads silently without annoying users with CAPTCHAs.
  - **Strict Scoping**: All custom vanilla JavaScript is encapsulated securely inside ES6 Modules to prevent namespace collisions.
- **Modular Codebase**: Extracted and compiled via Vite, splitting monolithic CSS/JS blocks into cacheable chunks for instantaneous loading.

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, CSS3, ES6 JavaScript
- **Build Tool**: Vite v8
- **3D / Animations**: React, React Three Fiber, GSAP, Anime.js
- **Form Handling**: FormSubmit.co
- **Deployment**: Vercel / Render ready

## 💻 Running Locally

To run this project locally, clone the repository and run the Vite development server:

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

To build for production:

```bash
npm run build
```
