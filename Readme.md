## 🌟 Features

- **Modern & Responsive Design:** Built with a "vibe coding" aesthetic featuring glassmorphism, dynamic animations, and a rich dark-mode UI.
- **Dynamic Content:** Seamlessly displays my projects, skills, and professional experience.
- **Interactive Resume Section:** Includes specialized, downloadable resume variants tailored to different roles (Data Scientist, ML Engineer, AI Engineer, Data Analyst).
- **Contact & Social Links:** Direct links to my professional profiles and a functional contact form interface.

## 🛠️ Built With

- **HTML5:** Semantic and accessible web structure.
- **Vanilla CSS3:** Advanced styling using CSS Variables, Flexbox, Grid, custom animations, and gradients.
- **JavaScript:** Smooth scrolling, dynamic UI interactions, and mobile navigation toggles.
- **Typography & Icons:** Clean fonts (`Space Grotesk`, `Inter`, `JetBrains Mono`) from Google Fonts and crisp vector icons from FontAwesome.

## 💻 Local Development

To run this project locally, simply clone the repository and open `index.html` in your web browser. No complex build tools or dependencies are required!

```bash
# Clone the repository
git clone https://github.com/shivansh-mishraji/Resume-Webpage.git

# Navigate to the directory
cd Resume-Webpage

# Open index.html in your default browser
```

*(Alternatively, you can use a local server like VS Code's Live Server extension for a better development experience).*
